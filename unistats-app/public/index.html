      About these statistics
      
        
      
      
      
      
        
      
          This application explores ELSTAT statistics for the departments found
          in the selected data source. It is a thesis research tool.
        
      
        
      What the sources mean
      
        
      
          Live database means the API read the remote UniStats
          graph. Local snapshot means it used copies of the
          supplied RDF files, prepared on 8 October 2026. Auto mode falls back
          to this snapshot when the endpoint is unavailable. Institution labels,
          years and filter vocabulary are read from the selected source. Use
          Refresh data to discover new records immediately; cached metadata
          expires after five minutes. Light mode and Dark mode save your
          preference on this device.
        
      
        
      Missing is different from zero
      
        
      
          Available years are discovered from observations. The ETL generally
          omits zero cells; a missing result can mean zero, unavailable data or
          no coverage. Charts leave missing years as gaps. Birth-year ranges and
          unknown birth years remain separate recorded groups.
        
      
        
      Comparisons need context
      
        
      
          N+ uses each program’s normal duration, which can be four or five
          years. Mean-age queries use exact birth years only. Cohort and
          postgraduate pipeline indicators are aggregate proxies, not individual
          student tracking. Metadata does not encode historical university
          reorganizations.
        
      
        
      Counts and percentages
      
        
      
          Totals sum the observed counts for the active filters. Female share is
          calculated within that selected population. Counts from different
          datasets or different years must not be added as if they were unique
          people.
        
      
        
      
          The catalogue contains the 41 corrected thesis queries. Four-year
          cohort restrictions, the postgraduate scope and the DEP staff query
          follow the corrected edition dated 8 October 2026.
